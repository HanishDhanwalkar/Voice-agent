Publish to GitHub Pages in 2 Minutes

Follow these simple non-technical steps to host your personalized voice bot publicly for free:

1

Create a New GitHub Repository

Go to github.com/new, name your repository (e.g., my-voice-bot), set it to **Public**, and click **Create repository**.

2

Upload `index.html`

Click **creating a new file** or **uploading an existing file**, name the file exactly index.html, paste the code of this page into it, and click **Commit changes**.

3

Enable GitHub Pages

Go to **Settings** $\rightarrow$ **Pages** in your repository. Under **Build and deployment**, select Branch: main (or master) / Folder: /(root), then click **Save**.

4

Get Your Deployed URL

In 30–60 seconds, your site will be live at: https://yourusername.github.io/my-voice-bot/. Share this link for evaluation!
